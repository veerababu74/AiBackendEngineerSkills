# AI Engineering Mastery — Frameworks & ML Additional Modules

Adds **Pydantic, Machine Learning, LangChain, LangGraph, Google ADK, and PydanticAI** to the curriculum.

## Recommended order

1. Pydantic — validation and structured design
2. Machine Learning — algorithms, training, evaluation
3. LangChain — LLM apps and RAG
4. LangGraph — stateful workflows and orchestration
5. Google ADK — Gemini agents and deployment
6. PydanticAI — type-safe agents
7. Enterprise integration with FastAPI, DBs, queues, observability, cloud

## Framework comparison

| Framework | Primary purpose | Especially useful for |
|-----------|-----------------|------------------------|
| LangChain | LLM application components | RAG, integrations, pipelines |
| LangGraph | Stateful orchestration | Durable agents, multi-agent |
| Google ADK | Agent development | Gemini agents, Google Cloud |
| PydanticAI | Type-safe agents | Structured agents, DI |
| Pydantic | Data validation | APIs, tool args, structured outputs |

> Build one agent with LangChain, orchestrate with LangGraph, then rebuild a smaller equivalent in ADK and PydanticAI to learn design philosophies — do not rebuild everything four times first.

## Five major projects

1. End-to-end ML Prediction Platform — Pandas, sklearn, Pydantic, FastAPI, MongoDB

4. Gemini Enterprise Agent Platform — Google ADK, Gemini, Agent Engine, FastAPI
